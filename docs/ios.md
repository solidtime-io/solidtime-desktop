# solidtime on iOS

The iOS app reuses the Vue renderer (`src/renderer`) and wraps it in a native
shell with [Capacitor](https://capacitorjs.com). Electron itself does not run on
iOS, so the desktop main process (`src/main`) is **not** part of the iOS build.

## What works vs. what doesn't

iOS sandboxes every app, so the desktop features that observe the rest of the
system have no equivalent and are disabled on mobile:

| Feature                     | Desktop | iOS |
| --------------------------- | :-----: | :-: |
| Manual time tracking + sync |   ✅    | ✅  |
| OAuth login (PKCE)          |   ✅    | ✅  |
| Automatic activity tracking |   ✅    | ❌  |
| Idle detection              |   ✅    | ❌  |
| Tray / menu-bar timer       |   ✅    | ❌  |
| Mini-window widget          |   ✅    | ❌  |
| In-app auto-updater         |   ✅    | ❌ (App Store) |

The iOS build is a **manual** time tracker. `src/renderer/src/platform/mobileBridge.ts`
implements the same `window.electronAPI` interface the desktop preload exposes,
with the unsupported capabilities as inert no-ops, so the shared renderer code
runs unchanged.

## Architecture

- `vite.config.ios.ts` — standalone Vite build of the renderer (no electron-vite,
  no Electron/Node modules). Output: `dist-ios/`.
- `src/renderer/ios.html` + `src/renderer/src/ios.ts` — iOS entry point. Installs
  the Capacitor bridge before mounting Vue.
- `src/renderer/src/platform/` — platform detection + the mobile bridge shim.
- `capacitor.config.ts` — Capacitor config (`appId: io.solidtime.mobile`).
- `ios/` — generated native Xcode project (committed; web assets under
  `ios/App/App/public` are gitignored and regenerated by `cap sync`).

OAuth returns to `solidtime://oauth/callback`, registered as an external URL
scheme in `ios/App/App/Info.plist` and delivered to the app via `@capacitor/app`'s
`appUrlOpen` event.

## Commands

```bash
npm run dev:ios      # Vite dev server (renderer in a desktop browser)
npm run build:ios    # Build the web bundle into dist-ios/
npm run sync:ios     # build:ios + copy assets into the iOS project (cap sync)
npx cap open ios     # Open the project in Xcode to run on a simulator/device
```

Typical loop: `npm run sync:ios && npx cap open ios`, then Run in Xcode.

## Requirements

- Xcode (with an iOS simulator or a provisioned device)
- Capacitor 8 uses Swift Package Manager — no CocoaPods install required.
